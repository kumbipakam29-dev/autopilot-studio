## Application safety checklist

- Never pay registration, training, certification, equipment-deposit or “account activation” fees.
- Use only the official domain; do not install unknown APKs or remote-access software sent by a recruiter.
- Check the legal entity, privacy policy, contract, task acceptance criteria, minimum payout, currency conversion and fees.
- Never use another person's account, falsify location/identity, or bypass country restrictions.
- Do not submit passwords, OTPs, recovery codes or card PINs. Provide identity/tax documents only through a verified official onboarding flow when genuinely required.
- For bug bounty work, test only assets explicitly in scope and follow program rules. No autonomous scanning or submission without human review.
- Treat advertised rates as conditional, not expected earnings. Track actual accepted hours/tasks and net payout.

## Agent workflow and statuses

1. **Opportunity Hunter** — add only opportunities with a primary/official source.
2. **Eligibility Check** — record country, language, age, device and skills requirements.
3. **Payout Check** — record methods, minimums, timing, fees and currency only if the source states them.
4. **Risk Review** — flag upfront fees, guaranteed-income claims, suspicious downloads or off-platform payment requests.
5. **Human application gate** — prepare application notes; never claim applied unless the user confirms submission.
6. **Outcome tracker** — use exactly these states: `Found` → `Source checked` → `Eligibility checked` → `Ready to apply` → `Applied (user-confirmed)` → `Accepted` → `Work submitted` → `Work approved` → `Payment verified`.
