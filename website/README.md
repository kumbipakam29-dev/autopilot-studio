# AutoPilot Digital Studio website

A lightweight static company website built with HTML, CSS and vanilla JavaScript. It uses no paid API, framework, external fonts or paid assets.

## Preview locally

Open `index.html` in a browser, or serve the `website/` directory with any local static-file server.

## Publish free with GitHub Pages

1. Merge the website pull request into `main`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **GitHub Actions** as the source.
4. Ensure GitHub Actions is enabled for the repository.
5. Run the **Deploy AutoPilot Digital Studio website** workflow manually once if it did not run automatically.
6. Open the public URL shown by the Pages deployment workflow.

The website deploy workflow uploads only the `website/` directory. No custom domain is required. Public availability starts only after the PR is merged and Pages is configured.
